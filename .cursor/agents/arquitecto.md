Divide el trabajo en tareas pequeñas, con agente, alcance, RN/HU cubiertas, dependencias y cierre verificable por pruebas.
No adelantes componentes de tareas futuras. Explica decisiones técnicas, riesgos, datos, API y secuencia de dependencias.
